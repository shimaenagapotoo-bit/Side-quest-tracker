✦ はじめての方へ

AY SIDE QUESTは、7つの分野で「やってみたい」「やってみた」を記録して、自分の挑戦を振り返る無料のミニアプリです。

1. 記録の守り方を選ぼう

初回は「暗号化して開始」がおすすめ。自分だけの10文字以上のパスフレーズを設定してください。忘れると復元できないため、安全に保管しましょう。

2. 「＋ ADD QUEST」で挑戦を登録

クエスト名・日付・7分野のいずれかを選びます。初挑戦なら First Time、一人で挑戦するなら Solo にチェック。Courage（勇気度）は1〜5で記録できます。

3. 達成したら「COMPLETE」

XPが増えてレベルアップ！ HOMEでは分野別の記録を、YEARでは1年間の振り返りを見られます。XPはゲーム感覚で楽しむための目安です。

4. SNS共有は自分で選べる

記録カードの「共有」を押すとプレビューが表示されます。日付と感想は最初は共有されない設定です。内容を確認してから、Xへの投稿やInstagram向けの画像共有を選んでください。アプリ自体を友人に伝えるときは SETTINGS →「アプリのリンクを共有」。

🔐 個人情報と保存先について

メールアドレス・氏名・電話番号の登録は不要です。アプリ自体は利用者の記録を外部サーバーへ送信せず、同じ端末・ブラウザ内に保存します。ほかの利用者とは自動共有されず、端末間の同期もありません。暗号化モードなら保存する記録をパスフレーズで保護します。

ただしGitHub Pagesの配信事業者は、サイトへのアクセス時にIPアドレスをセキュリティ目的で記録します。また端末やブラウザの侵害、コードの不正な変更などのリスクをゼロにはできません。個人情報や第三者の秘密は記録しないことをおすすめします。

💾 大事な記録はバックアップ

SETTINGS →「JSONバックアップを保存」で定期的に保管してください。暗号化なしのモードやCSV書き出しには記録がそのまま入るので、共有・保存先に注意してください。ブラウザのデータを消すと記録も失われる場合があります。

📱 端末内だけで使う（暗号化なし）

解除不要で手軽。ただし同じ端末・ブラウザを使える人には見られる可能性があります。

暗号化のパスフレーズを忘れると記録を復元できません。安全な場所に控えてください。ブラウザのデータ削除に備え、定期的なバックアップも必要です。
